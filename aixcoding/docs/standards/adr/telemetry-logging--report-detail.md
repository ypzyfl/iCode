# ADR-telemetry-logging--report-detail：完整埋点报文的文件日志与 TUI 专用入口

- 责任人：兰荣达
- 状态：已确认
- 确认日期： 2026-11-13
- 确认意见： 已确认

> 本文记录决策时点。日志分层规则见 DEVELOPMENT.md。

## 背景

ADR-0017 将技术明细留在独立文件卷并阻止其进入普通 F6 日志。内网验证新增需求是在 F6 的 `aixcoding` 页签直接核对完整上报参数与真实连接地址。

## 决策

启用本机诊断后，每次独立埋点 POST 产生一条可核对的完整报文记录。记录复用 detail 文件卷，并通过独立、有界的内存缓冲投影到 F6 的专用详情组件。请求 JSON 和 URL 参数保留原值，认证头不采集。缺少真实对端信息时显示未知。普通 F6 日志和主卷继续使用原有路由，其他 detail 事件仍由 ADR-0017 管理。

## 理由

现有普通日志有行长裁剪，无法完整核对报文。让 detail 冒泡会同时改变普通日志和 root sinks 的可见范围。专用组件能保留完整值并把上游接触面限制在一个页签挂点。

## 后果

排查人员可在本机查看或复制报文。历史由文件轮转约束，TUI 按整条记录保留最近报文。上游页签布局和 HTTP 连接扩展由行为测试保护。

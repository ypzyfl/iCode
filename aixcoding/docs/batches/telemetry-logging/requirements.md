# 需求：企业埋点上报日志

内网验证时，需要从本机核对每次独立埋点 HTTP 请求发往哪个接口、连到哪个 IP、实际发送了什么数据，以及是否收到响应。

- L01：开启诊断后，现有 `aixcoding.detail.log` 逐次记录 `tool-detail/save`、`tool-detail/update`、`ai-code/save` 的实际 POST。记录方法、完整 URL（含查询参数）、对端 IP 和端口、状态或失败类型、耗时，以及完整 JSON 参数和原始值。
- L02：TUI 的 F6 → `aixcoding` 可选择一条上报，查看和复制同一条记录的完整参数。请求体中原有的 ID、长字段、嵌套对象和数组均保留。
- L03：没有连接地址可用时，保留目标 URL 并明确显示对端未知。HTTP 失败和网络失败仍可核对请求。诊断开关默认关闭，认证请求头不采集。
- L04：诊断不影响上报报文、队列顺序、发送结果统计或原有日志展示。首批覆盖独立上报，随模型请求附带的 telemetry 另行评估。

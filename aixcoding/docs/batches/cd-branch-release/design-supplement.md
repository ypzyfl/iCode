## 拟批准范围

将 `.github/workflows/cd.yml` 的版本分支白名单从两个 0.35.2 分支改为 `main_aixcoding_cli_X.Y.Z` 和 `main_aixcoding_cli_X.Y.Z_final` 的通用规则。匹配完整分支名，版本为三段数字。适用于当前及后续版本。

仍要求在 `ypzyfl/iCode` 手动勾选发布，所选分支与 `ref` 一致，并用触发时的 SHA 完成 CI、构建和预发布。标签继续从 wheel 版本、运行 ID 和运行次数生成。正式发布及 PyPI 条件沿用原规则。

## R2 清单

只改 `.github/workflows/cd.yml` 已登记的 dispatch 和 resolve-build 两处，调整开关说明、分支判断和错误提示。相对 `9b6c22ae` 的候选差异为 +3/−4。归档时保留已签认的 0.35.2 原设计和签认记录。

## 验证

候选补丁通过九组分支匹配的 Bash 验证，包括 0.35.2、0.36.0、1.2.3、`_final` 和常见非法分支名。正式发布条件和 PyPI 无差异。

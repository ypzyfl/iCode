# 登录与登录状态

本节介绍 AIxCoding-CLI 的账号登录功能：何时需要登录、如何用 `/login` 完成登录、登录状态的保存方式，以及登出方法。

**使用 AIxCoding-CLI 需先登录，登录后才能使用管理员分配的模型。** 打开后，界面顶栏右侧会显示登录状态徽章（未登录时显示灰色 ●「未登录」）。如果顶栏右侧完全没有登录相关字样，说明安装的是不支持登录的旧版本，请先[安装新版本](./getting-started.md#1-安装-aixcoding-cli)，再按本节步骤登录。

## 1. 怎么登录

在输入框输入 `/login`，或点击顶栏右侧的灰色 ●「未登录」徽章，均可打开登录对话框。

1. 对话框显示一串用户码，并自动在浏览器打开验证页面。
2. 在浏览器页面中核对你的账号信息，点击确认授权。
3. 回到终端，提示已登录，顶栏出现绿色 ● 徽章。

对话框倒计时结束前未完成授权时登录失败；取消对话框不会保存任何内容。

## 2. 登录状态的保存

- 凭据使用操作系统级加密保存在本机（Windows：`%APPDATA%\chrys\users\`；Linux / macOS：`~/.chrys/users/`）。
- 下次启动时会自动静默校验；即使离线启动，只要本机凭据仍在，顶栏仍显示已登录。
- 顶栏徽章：已登录显示绿色，未登录显示灰色 ●「未登录」；将鼠标悬停在徽章上可查看详情。

## 3. 登录失效了怎么办

顶栏徽章变灰（未登录）时，重新执行 `/login` 即可；正在进行的对话不会中断。

## 4. 登出

输入 `/logout` 清除本机保存的凭据并退出登录。已处于登出状态时执行该命令是安全的，仅提示当前状态。

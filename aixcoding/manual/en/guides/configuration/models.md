# Switch models

AIxCoding-CLI does not support creating models or model profiles; it only supports switching models, which you can do directly in the interface. Available models are assigned by the administrator and appear in the model list only after assignment. Before using a model, [sign in](../../start/login.md#signing-in-and-sign-in-state) first; after signing in, you can use the default assigned model.

- Click the model name on the status bar above the input box (for example `$ T-MTP Qwen3.6`) to open the model picker, then confirm with a mouse click or by selecting with the up/down arrow keys and pressing Enter.
- Type `$` in the input box: the model list appears above it. Keep typing to filter the results, select with the up/down arrow keys, and press Enter to confirm.

After switching, the status bar shows the new model name. Models cannot be switched while an agent is running.

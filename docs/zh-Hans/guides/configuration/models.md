# 切换模型

AIxCoding-CLI 不支持创建模型、模型配置，仅支持切换模型，可直接在界面中操作模型切换。可用模型由管理员分配，分配完成后才会显示在界面的模型列表中。使用模型前需先[登录](../../start/login.md)，登录后即可使用默认分配的模型。

- 点击输入栏上方状态栏中的模型名称（如 `$ T-MTP Qwen3.6`），打开模型选择窗口，通过鼠标点击，或使用上下方向键选择模型后按回车确认。
- 在输入栏中输入 `$`，模型列表会显示在输入栏上方；继续输入可筛选结果，使用上下方向键选择后按回车确认。

切换后，状态栏会显示新的模型名称。智能体正在运行时不能切换模型。

# Switching models

AIxCoding-CLI does not support creating models or model configurations; it only supports switching models, which you can do directly in the interface. Available models are assigned by the administrator and appear in the model list only after they are assigned. [Sign in](../../start/login.md#signing-in-and-sign-in-state) before using models; once signed in, you can use the default assigned model.

- Click the model name in the status bar above the input box (for example `$ T-MTP Qwen3.6`) to open the model selection window, then pick a model by clicking, or with the arrow keys and Enter.
- Type `$` in the input box; the model list appears above the input box. Keep typing to filter the results, then choose with the arrow keys and Enter.

After switching, the status bar shows the new model name. Models cannot be switched while an agent is running.
